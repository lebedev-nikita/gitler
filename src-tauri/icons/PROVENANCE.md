# Icon provenance

All five bundle icons were rasterized from the repository's existing
`assets/icon.svg` using the official Tauri icon command. The source was present
in initial commit `d67e6ecfc09f5eed74a6ca6d0126de90f3808251`.

The PNG files embed this origin in their metadata. The ICO and ICNS containers
derive from the same source. No generative prompt was used.
